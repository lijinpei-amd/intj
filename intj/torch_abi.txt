# Verified torch ABIs, one stanza per (major, minor).
#
# Never write a row by hand.  Run `python -m intj.torch_abi` on the target
# build and paste the stanza it prints: every number in it is measured against
# torch's own accessors, so a pasted stanza is verified by construction, while
# an edited one is a guess -- and a wrong offset cannot raise, it reads
# whatever lies at that address.
#
# Format: `[major.minor]` opens a stanza, `name: ...` is a row, an indented
# line continues the row above it, and `#` starts a comment.
#
#   layout: byte offsets into PyObject / TensorImpl / StorageImpl
#   dtypes: <at::ScalarType code>=<torch's spelling>:<element size>
#
# The dtypes row is what makes a version *known*: intj refuses to read tensors
# through these offsets unless the running torch's dtypes are exactly the ones
# that were there when the offsets were measured.
