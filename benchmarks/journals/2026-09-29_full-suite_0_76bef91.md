## Result

**No regression.** Rule: slower by >3 % and by >2 ns (ns rows) or >0.1 us (us rows).

- **Gate vs `globals-tensor` (`c7125b1`):** 0 of 194 rows flagged. Host rows (`launch_host`, `launch_sweep`,
  `launch_last_key`, `ffi_paths`, `launch_dynamic` spec_key, `launch_readme` decode) all within -3.0 % .. +2.2 %.
  GPU enqueue rows read 5-17 % *faster* (`launch_gpu`, `ffi_compare`, `ffi_sweep` "FFI empty kernel", TVM FFI's
  own rows included), which is the baseline's slow GPU window (documented in its journal), not these commits.
- **Gate vs `interp-refusal` (`839a0e0`), GPU-row cross-check:** 0 rows flagged; INTJ `ffi_compare` kernels
  +0.4 .. +1.4 %, `hip_module` INTJ -0.1 %, `launch_gpu` -5.6 .. +1.3 %.
- **`kernel_cache`:** largest intj-column increase is 5-word `hit/64` 3.28 -> 3.97 ns (+0.69 ns), below the 2 ns
  floor; 1-word `hit/8` moved -0.65 ns the other way. Sub-ns jitter of single-round Google Benchmark rows.
- **`bench_mix.py` A/B (144 rows):** all within -3.3 % .. +2.5 % (largest slowdown: 32 args, 0 % constexpr,
  tensor, repeat 97.9 -> 100.3 ns, +2.4 ns / +2.5 %); none flagged.
