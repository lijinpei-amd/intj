Every aggregate number is the median of three **process results**. TVM FFI's
no-op script and both INTJ scripts use nine 1,000-call batches (process
median of batch values); callback has 10,000 C++ loop calls per path,
kwargs and unpack each have 1,000,000 calls per path (one mean per process,
using `time.time()`). GPU launch timers stop **before** synchronization, so
queue backpressure can affect host enqueue time. The no-op rows launch no
GPU kernel. The INTJ Python utility adapters time a shared zero-argument
wrapper, unlike TVM FFI's direct loops; compare *differences within each
script* only.

### C++ to Python callback

|---|---:|

| pycallback+from_dlpack | 15.660 |
| INTJ cold compile callback + cache | 0.420 |

TVM FFI calls back into Python through a C++ loop with three tensors;
the second path performs explicit DLPack conversions. INTJ calls its
Python compile callback only on a cache miss: 9,000 unique keys per process,
with a checked total of 9,100 callbacks including warmup. The measured INTJ
cold path also decodes arguments and inserts cache entries. Its fake kernel
address is never passed to a GPU driver (`no_gpu=True`). No cross-project
callback speedup ratio can be inferred from these different operations.
