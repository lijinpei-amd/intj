## Command

```sh
for i in 1 2 3 4 5; do
  export TRITON_HOME=$(mktemp -d)
  PYTHONPATH=$PWD taskset -c 0 python benchmarks/bench_launch.py --readme --iters 20000 --batches 7
  rm -rf "$TRITON_HOME"
done
```

Five processes, each with an empty `TRITON_HOME` (so `build s` is a cold build).
Each process reports the median of seven 20000-call batches; the tables take the
median of the five processes. 2026-10-15 12:30:30 to 12:32:06 +08:00.

## Caveats

- Run 1's intj `grid=(1,)` (3.82 us) is above the other four (3.08-3.12 us);
  the median is unaffected.
- Host time per call, not GPU completion; `grid=(0,)` returns before decoding,
  so intj's host overhead is that row plus the decode row (~0.12 us).
