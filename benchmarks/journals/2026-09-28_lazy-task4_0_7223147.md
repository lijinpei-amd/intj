# Lazy launchers Task 4: `dynamic_options` for compile options and knobs (index 0)

Benchmark gate for Task 4 of `docs/superpowers/plans/2026-09-27-lazy-dynamic-launchers.md`
(compile options and `knobs.<group>.<name>` paths passed per call and keyed). No benchmarked
launcher declares dynamic values, so every launch path measured here renders as before except
for the `(void)dyn;` line and the `INTJ_NDYN` term.
Baseline: `2026-09-27_lazy-baseline_0_f507cfc.md`; Task 3: `2026-09-28_lazy-task3_0_a6292eb.md`.

## Environment

- Candidate: `7223147` (branch `develop`), clean checkout. The gate ran on `42ca029`, the same
  tree before its commit message was amended to record the gate result (the raw `commit=` lines
  say `42ca029`; `git diff 42ca029 7223147` is empty). A/B tree: detached worktree of `604046c`
  (Task 3 final, `/tmp/intj-lazy-t3`).

  `lazy-task4` `2.21, 6.11, 8.44` -> `2.51, 3.88, 6.24`; `lazy-task4-rerun` `2.39, 3.84, 6.22` -> `3.45, 3.82, 5.83`; A/B `3.45, 3.81, 5.80` -> `3.17, 3.63, 5.55`
  (the A/B files log `/proc/loadavg` per process).

## Result

**No regression attributable to Task 4.** In the interleaved A/B against Task 3 (`604046c`)
every host, sweep and last-key row is within 1 ns (-0.4..+0.9 ns). Flagged against the
baseline:

| row | baseline | lazy-task4 | rerun | Task 3 (run / rerun) | why |
|---|---:|---:|---:|---:|---|
| ffi_paths INTJ cold compile callback + cache | 404.6 | 708.7 | 707.3 | 709.2 / 707.3 | Task 2's accepted per-launcher miss callback |
| launch_readme decode ns, static_compile | 89.7 | 96.3 | 94.1 | 95.3 / 97.1 | Task 2's accepted `spec_key(launcher, device, *args)` row |
| launch_readme decode ns, runtime_shim | 91.1 | 95.7 | 94.9 | 93.9 / 94.2 | same |
| launch_last_key 32 alternate | 103.3 | 112.1 | 112.6 | 112.1 / 112.6 | Task 3's code placement (A/B vs 604046c: +0.8) |

| launch_sweep 32 int | 105.9 | 113.9 | 113.3 | 113.7 / 113.4 | same (A/B +0.0) |

The eight `launch_gpu` rows other than `auto map` flagged in the first run only (+4..+10%, GPU
submission noise, about 20% between processes); in the rerun all are within -3.4..+1.0%.
No `-falign-functions=64` A/B was needed: the placement-sensitive rows match Task 3 already.

### lazy-task4-ab.sh

```bash
#!/bin/bash
# 5 interleaved rounds: 604046c (Task 3) worktree vs HEAD
# rows: host matrix (acceptance), sweep and last-key (the rows flagged vs baseline)
set -u
out=/tmp/intj-bench/lazy-task4-ab; mkdir -p $out
repo=/mnt/nvme2/jinpli/workspace/home/jinpli/development/intj
PY=/tmp/gb2/bin/python
for r in 0 1 2 3 4; do
  for tree in t3:/tmp/intj-lazy-t3 lazy-task4:$repo; do
    name=${tree%%:*}; dir=${tree#*:}
    for c in "launch_host|--no-gpu" "launch_sweep|--sweep" "launch_last_key|--last-key"; do
      case=${c%%|*}; flag=${c#*|}
      (cd $dir; echo "commit=$(git rev-parse HEAD)"; echo "load=$(cat /proc/loadavg)"
       PYTHONPATH=$dir INTJ_BENCHMARK_ROOT=/tmp/gbench taskset -c 0 $PY benchmarks/bench_launch.py $flag --iters 100000 --batches 9 2>&1
      ) > $out/${name}_r${r}_${case}.txt
    done
  done
done
echo done > $out/DONE
```
